#Html CSS JS Simple

Proyecto web simple con interfaz moderna que incluye un formulario de inicio de sesión, registro y panel de inicio.

#Archivos
- `index.html`      - Formulario de Login y Registro.
- `inicio.html`     - Página de bienvenida.
- `css/style.css`   - Estilos globales.
- `js/main.js`      - Validaciones y redirección.
